    Profil

    Réflexion

    Le modèle rédige un plan, un brouillon, puis se relit. Chaque passe est une génération complète : à 3, une réponse prend environ cinq fois plus de temps. Sur un téléphone ancien, c'est long.

    Recherche web

    Éteinte, l'application ne contacte aucun serveur pendant une conversation. Allumée, ta question est envoyée à un moteur de recherche.

    Génération

    Une valeur élevée consomme plus de mémoire au chargement du modèle. Le changement s'applique au prochain chargement.
